### 🛠️ Proyectos destacados

#### 📦 Sistema de Gestión — Centro de Reciclados Turin *(2026 · en producción)*
Sistema de escritorio para un centro de reciclado: gestión de boletas, clientes, mercadería y pesadas.
- **Arquitectura:** Electron (shell de escritorio) + NestJS (API REST/WebSockets) + React/Vite (SPA) sobre PostgreSQL
- **Integraciones:** balanzas industriales por puerto serie, impresión térmica de tickets, multi-sede vía VPN (Tailscale)
- **CI/CD:** build y empaquetado automático del instalador Windows con GitHub Actions

#### 🖨️ Sistema de Gestión — Gráfica Digital DC *(2025-2026 · en producción)*
ERP a medida para imprenta y librería: órdenes de trabajo, presupuestos, facturación electrónica AFIP y caja.
- **Stack:** React + Vite, Node.js/Express, MySQL, empaquetado como app de escritorio Windows (Electron) con auto-actualización
- **Integraciones:** facturación AFIP (CAE + QR fiscal), Mercado Pago, impresión térmica ESC/POS, archivo automático en Google Drive

> 🔒 Ambos repositorios son privados por tratarse de sistemas productivos de clientes. Con gusto comparto capturas, una demo o acceso puntual ante consultas.
